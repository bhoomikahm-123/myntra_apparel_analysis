# Myntra Apparel Analysis (Excel Project)

This project analyzes apparel product data from Myntra to generate insights using Microsoft Excel.

## 📁 Dataset

The dataset contains ~100 rows of mock data with the following columns:
- Product ID
- Product Name
- Brand
- Category (T-Shirt, Jeans, Shoes, etc.)
- MRP (Original Price)
- Selling Price
- Discount %
- Rating (Out of 5)
- Number of Ratings
- Available Sizes (S, M, L, XL, XXL)

## 🧠 Objectives

- Analyze pricing, discounts, and rating patterns
- Explore size availability across products
- Visualize top-performing categories

## 📊 Excel Features Used

- **Data Cleaning**: Remove duplicates, handle missing values, format numbers
- **Formulas**: `IF()`, `SEARCH()`, `COUNTIF()`, `TEXTSPLIT()`, `ISNUMBER()`
- **Pivot Tables**: Group by category, price range, size, etc.
- **Charts**:
  - Bar Chart: Top 5 categories with highest discounts
  - Pie Chart: Size availability distribution
  - Line Chart: Average rating by price range
- **Slicers** for interactive filtering

## 📈 Key Insights

- Certain categories offer the highest discounts (e.g., T-Shirts, Footwear)
- Sizes M and L are most common; XL/XXL less available
- Products priced between ₹500–999 received the best ratings
